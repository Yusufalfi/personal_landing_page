# Yusuf Alfi — React + Tailwind Portfolio

Neo-Brutalist personal portfolio for an RPA Developer, Web Automation and Web Scraping.

## Stack

- React
- Vite
- Tailwind CSS v4
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Main files

- `src/App.jsx` — page composition
- `src/components/` — UI sections
- `src/data/projects.js` — project content
- `src/index.css` — Tailwind import + global styles

Replace the placeholder email and LinkedIn URL in `Contact.jsx`.
